Injeção de prompt

em inglês, prompt injection

Injeção de prompt é quando um texto que o assistente lê (um email, uma página web, um PDF, um comentário num documento) traz instruções escondidas, e o modelo as segue como se viessem de ti. Acontece porque, para o modelo, tudo é texto: o teu pedido e o conteúdo que lhe dás para trabalhar chegam pelo mesmo canal, e nem sempre consegue distinguir quem manda.

Enquanto o assistente só responde, o risco é limitado: um resumo enviesado ou uma resposta estranha. Quando passa a agir (enviar emails, preencher formulários, mexer em ficheiros, como os agentes desta edição), uma instrução escondida pode virar ação: reencaminhar uma mensagem, abrir um site, apagar um ficheiro. A instrução pode estar em texto branco sobre fundo branco, num rodapé minúsculo ou nos metadados de um documento, invisível para ti mas legível para a IA. Os fornecedores têm defesas, mas nenhum diz que o problema está resolvido. A organização OWASP põe-no em primeiro lugar na sua lista de riscos das aplicações com modelos de linguagem. É por isso que a técnica desta edição pede ao agente que mostre as instruções que encontrar, em vez de as seguir.

Três hábitos práticos:

  • Separa ler de agir: para resumir emails ou páginas de terceiros, usa um assistente sem permissões para enviar, comprar ou apagar.
  • Exige confirmação nas ações sem volta: nada sai, se paga ou se apaga sem o teu «sim» explícito.
  • Desconfia de respostas que mudam de rumo: se o assistente propõe algo que não pediste, pergunta-lhe de onde veio a ideia e mostra-te a fonte.

Para aprofundar: OWASP, LLM01: Prompt Injection · Wikipédia, Prompt injection
